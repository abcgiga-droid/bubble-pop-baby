# 🫧 Bubbles — Bubble Pop Baby

Pop bubbles with baby dragon 🐲 and mouse 🐭. Zero-dependency PWA baby game.

Play: tap / drag to pop floating bubbles. No score, no lose, works offline fullscreen.

## Run locally
Just open `index.html` or serve statically:
```bash
npx serve .
# or
python3 -m http.server
```

## Host free on GitHub Pages
1. Push to GitHub (`main` branch, root folder)
2. `Settings > Pages > Deploy from branch > main / (root)`
3. Open `https://YOURNAME.github.io/bubble-pop-baby/` → Add to Home Screen

No build step needed.
